# ion_gym

ion_gym is a Python toolkit for ion optics simulation. Geometry, voltages, drive waveforms, gas conditions and the ion source are declared in a JSON specification file. The toolkit solves the fields and flies the ions with its own solver and trajectory kernel, from a script, a notebook or the browser dashboard.

These pages are the user manual, one chapter per page, plus catalogs of the shipped example decks and notebooks. The same manual is available as a [PDF](https://github.com/bhclowers/ion_gym/blob/main/docs/ion_gym_user_manual.pdf).
