# Manuscript examples

These scripts and notebooks make the figures in the ion_gym manuscript and its
Supporting Information. Each one loads a shipped deck, or a deck generated in
this folder, and writes its output to `outputs_dir("manuscript_examples", <device>)`.
In a clone, that is `outputs/manuscript_examples/<device>/` under the checkout root.
In an installed package, it is the same path under the working folder.

This folder sits at the repository root beside `notebooks/` and, like it, is not part
of the installed package. Run these from a clone.

## Figure to producer map

| Figure | Producer | Run time (measured) |
|---|---|---|
| Fig. 2, workflow (rod quadrupole) | `quadrupole/make_fig2_workflow.py` | about 3 s with cached bases |
| Fig. 3, stability zones (sin and square drive) | `quadrupole/make_fig3_zones.py` | transfer matrix only, nothing flown |
| Fig. 4, flown stability check | `quadrupole/make_fig4_stability.py --grid 13` | about 20 s |
| Einzel optimization | `einzel/make_fig_einzel_opt.py` | flies the optimizer |
| SI: einzel landscape | `einzel/make_fig_einzel_landscape.py` | needs the record from the line above |
| SI: integrator comparison | `quadrupole/integrator_compare.py` | write-up in `INTEGRATOR_COMPARISON.md`, banked output in `integrator_compare.out.txt` |
| RF drift-cell mechanism | `drift_cell/24_srig_rf_mechanism.ipynb` | flies the bank |
| RF drift-cell manuscript panels | `drift_cell/25_manuscript_figures.ipynb` | reads the bank |
| Run-export figure | `drift_cell/26_run_export_figure.ipynb` | |

Teaching notebooks for the stability charts: `quadrupole/sin_stability.ipynb`
and `quadrupole/digital_stability.ipynb`.

## Run order

1. Quadrupole: run `make_digital_quad_deck.py` once if `decks/quadrupole_digital_3d.json`
   is missing (the committed copy is current). Figures 2, 3 and 4 can then run in any order.
2. Einzel: run `make_fig_einzel_opt.py` before `make_fig_einzel_landscape.py`. The
   landscape figure takes the returned bias only from the banked optimizer record
   and refuses to run without it.
3. Drift cell: run notebook 24 first. It flies the ensemble and writes the bank to
   `outputs_dir("manuscript_examples", "drift_cell", "data")`. Notebooks 25 and 26
   read that bank. `make_rf_drift_cell.py` regenerates the shipped
   `examples/` RF drift-cell deck and is needed only for geometry sweeps.

Run the scripts from any directory. Each one adds only its own folder to the import path,
so ion_gym must be installed (`pip install -e .` in a clone).

## Provenance

These are copies. The originals stay in the development tree. The notebooks were
first generated by internal tooling, and the copies here were then edited to use
public paths. Edit the copies directly. Regenerating from the internal generators
would bring back paths that do not exist in a release.
